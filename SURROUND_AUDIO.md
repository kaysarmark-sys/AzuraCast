# Stereo and Atmos playback

The former 5.1 AutoDJ output option has been retired.

Choose **Station Profile → Edit → AutoDJ → Stream Mode**:

- **Stereo:** conventional stereo streams; Atmos HLS is disabled.
- **Dolby Atmos (HLS):** Atmos HLS is the public stream; conventional broadcasts are disabled. Non-Atmos tracks use stereo Dolby Digital Plus fallback.

Save and restart the station after changing modes. Existing 5.1 settings are normalized to stereo; existing Atmos-enabled stations retain Atmos mode.

See [ATMOS_HLS.md](ATMOS_HLS.md) for format requirements and buffering details.
